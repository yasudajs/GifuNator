# GifuNator（ギフネイター）🏔️

**岐阜にまつわる言葉を当てる「20の質問」推理ゲーム！**

アプリが岐阜県に関するお題（観光地、グルメ、歴史、伝統工芸など）を1つ心に思い浮かべます。  
プレイヤーは提示された質問をうまく選び、最大20問以内に「はい」「いいえ」の手がかりから正解を導き出しましょう！

---

## 🌟 主な特徴

- **完全無料・ブラウザ単体でサクサク動作**:
  - サーバー代やAPI課金リスクゼロ。GitHub Pages 等で即座に公開可能。
- **美濃と飛騨を網羅した30選の初期お題**:
  - 白川郷、岐阜城、飛騨牛、モネの池、関の刃物、鵜飼いなど、岐阜の魅力を凝縮。
- **テンポの良いカード選択型システム**:
  - ランダムに提示される3つの質問から選ぶだけなので、スマホでも片手でサクサク遊べます。
- **2つの解答モード**:
  - **初級（候補から選択）**: 30個のお題ボタンから絞り込んでタップ解答。
  - **上級（直接入力）**: キーボードから漢字・ひらがなで直接入力して解答。
- **岐阜の魅力・豆知識解説＆Xシェア機能**:
  - 正解するとお題の詳しい解説や写真スポット情報が表示され、観光振興にもつながります。

---

## 🎮 遊び方

1. **ゲームスタート**:
   - アプリがお題を1つランダムに決定します。
2. **質問する**:
   - 画面に提示された3つの質問カードから、気になるものを1つ選んでタップします。
   - 「質問を更新」ボタンで別の組み合わせを引くこともできます。
3. **推理する**:
   - アプリが「はい」または「いいえ」で回答します。履歴欄にどんどん手がかりが蓄積されます。
4. **アタック（解答）**:
   - 「これだ！」とひらめいたら、下の「候補から選ぶ」または「直接入力」から解答します。
   - 少ない質問数で当てると「伝説の岐阜神級」「飛騨牛・長良川級」などの高評価称号がもらえます！
5. **ゲームオーバー**:
   - 20問使い切るとギブアップとなり、正解の豆知識が表示されます。

## 🛠️ 技術スタック

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+ Vanilla)
- **データ**: JSON (`data/topics.json`, `data/questions.json`)
- **外部依存**: なし（ビルドステップ不要）

## 🚀 GitHub Pages での公開手順

1. リポジトリの **Settings**（設定）を開く
2. 左メニューの **Pages** を選択
3. **Build and deployment** の Source で **Deploy from a branch** を選択
4. Branch に **main** / **/(root)** を選択して **Save**
5. 数分後、`https://yasudajs.github.io/GifuNator/` でゲームが世界中に公開されます！
